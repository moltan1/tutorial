# NES Emulator Project

This project is an attempt to create a Nintendo Entertainment System (NES) emulator that runs in the web browser.

**Features (Planned):**
*   Web-based interface for controls and display.
*   Support for game ROMs placed in the `roms` directory.
*   CPU, PPU, and APU emulation.
*   Support for various mappers.

This is a work in progress.
